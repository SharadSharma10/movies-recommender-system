# 🎬 Movie Recommendation System

A machine learning-powered movie recommendation web application built with **Python, Streamlit, Pandas, and Scikit-learn**. Discover movies similar to your favorites using a content-based recommendation approach and explore movie posters through The Movie Database (TMDB) API.

## ✨ Features

- 🎥 **Movie Recommendations:** Get suggestions for movies similar to your selected movie.
- 🤖 **Machine Learning:** Uses a precomputed movie similarity matrix to identify related movies.
- 🖼️ **Movie Posters:** Fetches movie poster images using the TMDB API.
- ⚡ **Fast Predictions:** Loads preprocessed movie data and similarity scores instead of recalculating them for every request.
- 🖥️ **Interactive UI:** A simple, user-friendly interface powered by Streamlit.
- 🐍 **Python-Based:** Uses popular data science and machine learning libraries.

## 🧠 How It Works

The application follows a content-based recommendation workflow.

1. **Data preprocessing:** Movie metadata is cleaned and transformed into a format suitable for machine learning.
2. **Feature representation:** Relevant movie information is represented numerically.
3. **Similarity calculation:** Similarity scores between movies are calculated during model preparation.
4. **Model persistence:** Processed movie data and similarity scores are saved in serialized `.pkl` files.
5. **Movie selection:** The user selects a movie from the Streamlit interface.
6. **Recommendation generation:** The application retrieves similar movies using the precomputed similarity scores.
7. **Poster display:** The TMDB API is used to retrieve poster images for the recommended movies.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/SharadSharma10/movies-recommender-system.git
cd movies-recommender-system
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If `requirements.txt` is missing, create it with the dependencies required by your application, such as:

```text
streamlit==1.38.0
pandas==2.2.2
numpy==1.26.4
scikit-learn==1.5.1
requests
```

### 4. Configure the TMDB API

The application uses TMDB to retrieve movie posters.

1. Create an account at [The Movie Database (TMDB)](https://www.themoviedb.org/).
2. Request an API key through your account settings.
3. Configure the key using the environment variable expected by your application.

For example, if your code reads `TMDB_API_KEY`:

Create a `.env` file:

```env
TMDB_API_KEY=your_tmdb_api_key
```

Load the variable in Python using `python-dotenv`:

```python
import os
from dotenv import load_dotenv

load_dotenv()

api_key = os.getenv("TMDB_API_KEY")
```

Install `python-dotenv` if you use this approach:

```bash
pip install python-dotenv
```

**Security:** Never commit your API key or `.env` file to GitHub. Add `.env` to `.gitignore`.

### 5. Verify the Model Files

Ensure the following files are present in the locations expected by `app.py`:

- `movies_dict.pkl`
- `similarity.pkl`

If these files are generated by your notebook, execute the preprocessing and model-building cells to recreate them. If they are not included in the repository, obtain or generate them before launching the application.

### 6. Run the Application

```bash
streamlit run app.py
```

Open the local URL printed in your terminal, usually:

```text
http://localhost:8501
```

## ⚠️ Limitations

- Recommendations depend on the available movie metadata and similarity scores.
- Movie posters require a working TMDB API configuration and network connectivity.
- The system may not personalize recommendations based on an individual user's viewing history.
- Recommendation quality depends on the dataset, selected features, and preprocessing pipeline.
